# Cyvantas AI Agent v0.2.0

Foundation release archive for Cyvantas AI Agent.

## Included

- `releases/Cyvantas-AI-Agent-v0.2.0-foundation.zip` — project source archive from the v0.2.0 foundation package.
- The archive contains the provider bundles, agents, skills, rules, tools, MCP components, tests, and supporting documentation.

## Extract

```bash
unzip releases/Cyvantas-AI-Agent-v0.2.0-foundation.zip
cd pentest-agents-main
```

The repository currently stores the release as an archive so the complete package can be transferred without dropping files from the original bundle.
